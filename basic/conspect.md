переименование файлов в Linux:
```
mv oldname.txt newname.txt
```
типы данных в js:
```
typeof undefined; // "undefined"
typeof 0; // "number"
typeof 1n; // "bigint"
typeof true; // "boolean"
typeof "foo"; // "string"
typeof Symbol(); // "symbol"
typeof {}; // "object"
typeof null; // "object"
typeof function () {}; // "function"
```

вывод в консоль:
```
console.log();
console.warn();
console.error();
console.info();
```
