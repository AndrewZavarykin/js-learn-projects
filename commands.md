Linux:

`mkdir -p myproject` - создание директории

`touch file.txt` - создание файла

`mv file.txt newname.txt` - переименование файла

`rm file.txt` - удаление файла

`rm -rf myproject` - удаление директории с содержим



Node:

`npm init -y` - инициализация нового проекта Node.js

`npm install --save-dev jest` - установка Jest в режиме разработки

`npm install` - установка всех зависимостей из package.json

Git:

`git init` - инициализация репозитория Git

`git branch` - просмотр всех веток

`git branch -d my-branch` - удаление ветки

`git checkout -b my-branch` - создание и переключение на новую ветку

`git add -A` - добавление всех изменений в индекс

`git commit -m "message"` - коммит изменений с сообщением

`git push` - отправка изменений на сервер Git
